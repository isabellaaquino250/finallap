# FinalLap — landing page responsiva

Recriação front-end baseada na referência enviada.

## Como executar
- Extraia o ZIP.
- Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Tecnologias
- HTML5 semântico
- CSS moderno com Grid, Flexbox e media queries
- JavaScript vanilla
- GSAP 3 + ScrollTrigger via CDN
- Google Fonts: Playfair Display e DM Sans

## Observações
- As imagens disponíveis foram recortadas da captura de referência enviada, portanto mantêm a identidade visual, mas têm a resolução limitada pela própria captura.
- Os formulários são demonstrativos e exibem uma confirmação local; conecte-os a um backend/CRM para receber contatos reais.
- A navegação mobile ocupa a tela, anima o ícone hamburger para X e fecha ao selecionar um link.
- Há suporte a `prefers-reduced-motion` para respeitar preferências de acessibilidade.
